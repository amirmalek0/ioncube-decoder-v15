These are verified reconstruction profiles, not universal support for every program or protection option. Encoder 9.0.5 / PHP 5.5 includes verified legacy direct calls, runtime function declarations, and uniquely constrained opcode-mask recovery. External key material is still required for modes that encrypt body contents with an unavailable key.

Recognized binary ionCube inputs are identified alongside text-encoded files.
External-key protected files require the correct key material; a missing key
cannot be reconstructed from the protected file alone.

Dynamic-key protected files may require the complete project ZIP, including
key-generating companion files.
