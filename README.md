# ionCube Decoder v15

https://github.com/user-attachments/assets/467276e1-159d-4187-84b5-54300fe938b0

A commercial ionCube decoder that reconstructs readable PHP through a simple
web interface.

## Features

- Single and batch file decoding
- PHP preview and ZIP download
- Decode history and error diagnostics
- REST API
- Docker deployment
- Local or self-hosted operation

## Compatibility

- **Encoder:** 10.2.0 through 15.0.1
- **PHP:** 7.1, 7.2, 7.4, and 8.1 through 8.4

Support depends on the Encoder version, PHP target, and protection options used
for each file.

## How it works

The decoder validates the encoded container, extracts its bytecode records, and
reconstructs supported instructions and control flow as readable PHP.
